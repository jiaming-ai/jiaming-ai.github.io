Pose-aware Topological Mapping位姿感知拓扑建图

Abstract摘要

Humans navigate large, open-world environments not by maintaining a globally consistent metric map, but by forming cognitive maps—topological representations that support robust relocalization even under severe perceptual changes. This paradigm is inherently resilient to tracking failures, dynamic environments, and long-term appearance variations. A fundamental enabler of this robustness is sequential hypothesis testing (SHT), which humans implicitly perform to disambiguate perceptually aliased places over time.人类在大型开放世界中导航，靠的并不是维护一张全局一致的度量地图，而是形成认知地图——一种即使在感知发生剧烈变化时也能支持鲁棒重定位的拓扑表示。这种范式天然能够抵御跟踪失败、动态环境和长期外观变化。这种鲁棒性的一个根本支撑是序贯假设检验（sequential hypothesis testing，SHT）：人类会不自觉地借助它，随时间推移消解感知上相互混淆的地点。

Despite its importance, most robotic systems either (i) avoid aliasing through conservative data-association thresholds, or (ii) apply filtering only in a discrete place space constructed from keyframes. Such discretization restricts the hypothesis space, prevents reasoning in between stored views, and leads to brittle relocalization when observations do not perfectly overlap past frames.尽管如此重要，大多数机器人系统要么 (i) 通过保守的数据关联阈值来回避混淆，要么 (ii) 仅在由关键帧构成的离散地点空间中做滤波。这种离散化限制了假设空间，使系统无法在已存储的视角之间进行推理，一旦观测与历史帧无法完全重叠，重定位就会变得脆弱。

We propose a pose-aware online topological mapping system that performs SHT directly in continuous SE(3) space. Our approach maintains and updates a multi-hypothesis belief over the robot pose and the map topology, allowing robust relocalization and loop closure without relying on global metric consistency. Addressing continuous-domain SHT introduces two major challenges: (1) how to represent and update distributions in SE(3) efficiently, and (2) how to manage map uncertainty—as each perceptual aliasing event can spawn multiple plausible map branches, whose number can grow rapidly if not controlled.我们提出一种位姿感知的在线拓扑建图系统，直接在连续的 SE(3) 空间中进行 SHT。我们的方法对机器人位姿和地图拓扑维护并更新多假设信念，使其无需依赖全局度量一致性即可实现鲁棒的重定位与回环。在连续域中做 SHT 带来两大挑战：(1) 如何高效地在 SE(3) 上表示并更新分布；(2) 如何管理地图不确定性——每一次感知混淆都会衍生出多个看似合理的地图分支，若不加控制，其数量会迅速膨胀。

We introduce a Gaussian-mixture–based representation and a principled branch management strategy that together enable real-time inference, scalable map maintenance, and robust operation in dynamic, ambiguous, or previously unseen environments. This work provides the first practical continuous-space SHT framework for topological mapping, bringing robots closer to the reliability and flexibility of human navigation.我们引入基于高斯混合的表示和一套有原则的分支管理策略，二者共同实现了实时推理、可扩展的地图维护，以及在动态、含混或从未见过的环境中的鲁棒运行。这项工作提供了首个实用的、面向拓扑建图的连续空间 SHT 框架，使机器人更接近人类导航的可靠性与灵活性。

Data-Driven RL for Social Navigation面向社交导航的数据驱动强化学习

Abstract摘要

We propose a data-driven reinforcement learning framework for social navigation that turns real-world human–robot navigation logs into replayable "imagination environments." This approach allows robots to learn navigation policies directly from logged RGB-D data and human trajectories, eliminating the need for conventional simulators.我们提出一种数据驱动的社交导航强化学习框架，把真实世界的人机导航日志转化为可回放的“想象环境”。该方法让机器人直接从记录下来的 RGB-D 数据和人类轨迹中学习导航策略，无需传统模拟器。

The system reconstructs bird's-eye-view (BEV) maps from RGB-D observations and replays recorded human trajectories within these environments. The robot can then train and refine its navigation policies by interacting with these reconstructed scenarios, learning socially-aware behaviors from real-world data.系统根据 RGB-D 观测重建鸟瞰图（BEV）地图，并在这些环境中回放记录下来的人类轨迹。机器人随后通过与这些重建场景交互来训练并打磨导航策略，从真实世界数据中学习具备社交意识的行为。

This framework bridges the gap between simulation-based training and real-world deployment, enabling robots to learn from actual human–robot interactions without the complexities and limitations of traditional simulation environments.该框架弥合了基于仿真的训练与真实世界部署之间的鸿沟，使机器人能够从真实的人机交互中学习，而无需面对传统仿真环境的复杂性与局限。

Vision-Language Navigation视觉-语言导航

Abstract摘要

This project leverages vision–language models to enable zero-shot visual-language navigation without the need for explicit policy training. The system translates natural-language navigation instructions into differentiable cost functions defined over bird's-eye-view (BEV) scene representations.本项目利用视觉-语言模型实现零样本视觉-语言导航，无需显式的策略训练。系统把自然语言导航指令转换为定义在鸟瞰图（BEV）场景表示上的可微代价函数。

By optimizing or selecting trajectories that minimize these learned cost functions, the robot can follow complex natural language instructions while navigating through real-world environments. This approach eliminates the traditional requirement for large-scale policy training on navigation datasets.通过优化或挑选使这些代价函数最小的轨迹，机器人能够在真实环境中导航时遵循复杂的自然语言指令。这种方法免去了传统上在导航数据集上进行大规模策略训练的要求。

The method enables flexible, instruction-following navigation that can adapt to diverse language commands and environmental contexts, bridging vision, language, and action in a unified framework.该方法实现了灵活的、遵循指令的导航，可适应多样的语言指令与环境情境，在统一的框架中打通视觉、语言与动作。

Offline RL for Vision-Language-Action Models面向视觉-语言-动作模型的离线强化学习

Abstract摘要

This research focuses on using offline reinforcement learning to fine-tune vision–language–action (VLA) models using real robot interaction datasets collected in laboratory environments. Rather than training from scratch, we leverage pre-trained VLA models and adapt them to specific robotic tasks through offline RL.本研究聚焦于利用离线强化学习，基于在实验室环境中采集的真实机器人交互数据集来微调视觉-语言-动作（VLA）模型。我们不从零开始训练，而是借助预训练的 VLA 模型，通过离线 RL 使其适配具体的机器人任务。

By learning from logged interaction data, the system can improve task performance without requiring extensive online exploration, which can be costly and time-consuming in real-world robotics. This approach enables safer and more efficient learning from limited real-world data.通过从记录下来的交互数据中学习，系统无需大量在线探索即可提升任务表现，而在真实机器人场景中，在线探索往往成本高昂且耗时。这种方法能够在有限的真实世界数据上实现更安全、更高效的学习。

The method demonstrates how large-scale pre-trained models can be effectively specialized for robotic manipulation and navigation tasks through principled offline learning, accelerating the deployment of capable robot systems in real-world environments.该方法展示了如何通过有原则的离线学习，把大规模预训练模型有效地专门化到机器人操作与导航任务上，从而加速高能力机器人系统在真实环境中的部署。
